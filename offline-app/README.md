# 夏暮工作室离线预约 App

这个版本不需要联网，不用微信云开发，也不用登录。订单、节假日、补班规则都保存在当前手机/浏览器本地。

## 使用方式

电脑本地打开：

```bash
npx http-server offline-app -p 8080
```

手机和电脑在同一个 Wi-Fi 下时，用手机浏览器打开电脑显示的局域网地址，然后在浏览器菜单里选择“添加到主屏幕”。

也可以直接双击打开 `夏暮工作室预约App-双击打开.html` 使用，但部分手机浏览器只有通过网页服务访问时才会显示“安装/添加到桌面”。

## 功能

- 离线保存预约订单
- 自动计算工作日/节假日价格
- 支持节假日和补班日手动维护
- 内置 2026 年中国大陆法定节假日和调休上班日模板
- 自动计算加班费、超人费、订金
- 同场景同日期只拦截实际时间重叠；紧邻档期会醒目提醒棚主联系下一单客户
- 管理订单状态：待确认、已付订金、已完工、已取消
- 改签计数，第二次及以后提示 50 元改签费
- 本地数据导出/导入备份
- 导入备份支持合并导入和覆盖导入
- 同一设备多窗口自动同步；同时抢同一档期只会保存一笔
- 导入时自动跳过无效日期、信息不完整和撞档订单
- 取消订单会保留记录，不会继续占用档期

## 重要提醒

因为这是单机离线版，数据只存在当前手机上。关闭 App、关闭浏览器、手机关机重启，一般不会丢失预约信息；电脑关机也不会影响手机里已经保存的订单。

换手机、清理浏览器数据、卸载浏览器或恢复出厂设置前，请先在“设置”里导出备份。
