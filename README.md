# 摄影棚预约管理

**给摄影棚主使用的离线预约与记账工具。** 支持自定义工作室名称、Logo、置景和收费规则，提供安卓 App 和电脑网页版。无需账号、服务器或月费。

> 当前推荐：**公开版 v1.0.2** · Android 7.0 及以上 · 离线本地保存
> 手机与电脑的数据不会自动同步。升级、换机前请先导出备份。

## 2. 开始使用

1. **安装或打开**：安卓打开 APK；电脑先完整解压，再双击“电脑双击打开.html”。保持“电脑版文件”文件夹完整。
2. **首次配置**：填写工作室名称、Logo，添加置景及价格，再核对营业时间、订金和预约规则。
3. **录入预约**：选择置景与时间，填写客户信息，核对算价和档期提示后保存。
4. **记录到账**：实际收到订金或尾款后，在“收入”里记一笔。
5. **每天备份**：在“设置”导出 JSON 备份，存到应用之外。

**更新旧公开版：先备份，再直接覆盖安装，不要先卸载。** 夏暮专用版与公开版是两个独立应用，迁移时使用 JSON 备份导入。

[在线阅读使用说明](./public-app/使用说明.md) · 图文说明和一图流在完整包内，也可从 App 设置页查看。

## 3. 主要功能

| 功能 | 内容 |
| --- | --- |
| 工作室自定义 | 名称、Logo、联系方式、公告、预设主题和深色模式 |
| 置景管理 | 数量、名称、照片、价格、人数、排序、启停及共用场地 |
| 自动算价 | 工作日、周末、节假日价格，订金、加班费、超员费和改签费 |
| 档期检查 | 拦截实际时间重叠；收尾间隔不足时提示，不额外占用档期 |
| 订单管理 | 搜索、筛选、状态修改、改签及历史价格快照 |
| 收入记账 | 订金、尾款等实收明细，按日、周、月统计 |
| 数据备份 | JSON 导入导出、旧夏暮版数据迁移、本机异常恢复提示 |

节假日和调休日需要在设置中维护。软件不接入在线支付，不会自动确认客户付款。

## 4. 常见问题

**关机或重启会丢订单吗？**
正常退出或重启通常不会。卸载、清除应用或浏览器数据、设备损坏可能丢失，请定期备份。

**手机和电脑能自动同步吗？**
不能。公开版是离线单机工具；可用备份文件手动迁移，不能当作多人实时协作系统。

**为什么订单金额没有计入收入？**
订单金额是预计应收；只有手动保存的真实收款记录才计入收入。

**支持苹果手机吗？**
当前没有 iOS 安装包，APK 只能在安卓安装。
