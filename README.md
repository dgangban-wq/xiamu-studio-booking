# 夏暮工作室摄影棚预约管理系统

夏暮工作室摄影棚预约管理系统，包含离线安卓 App、离线电脑网页、微信小程序、微信云开发接口和电脑 Web 管理后台。

本仓库同时保存了“给朋友直接使用的成品”和“供开发者继续维护的源代码”。如果你不是程序员，先看下面的【普通使用者】部分即可。

---

## 一、先看结论

### 普通使用者：直接安装安卓 App

进入 `安卓安装包/` 文件夹，安装：

```text
夏暮工作室摄影棚预约-v1.2.apk
```

安卓 App 是离线单机版：

- 不需要联网。
- 不需要微信云开发。
- 订单、档期、收入和设置保存在当前手机。
- 关机、重启、正常关闭 App 不会删除数据。
- 不会自动同步到电脑或另一部手机。
- 换手机、卸载 App 或清除应用数据前，必须先导出备份。

完整说明书在：

```text
安卓安装包/图文使用说明书.html
安卓安装包/先读我-安卓App安装与使用说明.txt
安卓安装包/手机打开-一图流使用介绍.html
```

### 开发者：不同版本的数据不是自动互通的

| 版本 | 数据位置 | 是否联网 | 是否与其他端自动同步 |
| --- | --- | --- | --- |
| 安卓 App | 当前手机本地 | 不需要 | 否 |
| 离线电脑网页 | 当前电脑浏览器 | 不需要 | 否 |
| 微信小程序 | 微信云数据库 | 需要 | 是，可配合 Web 后台 |
| Web 管理后台 | 微信云数据库 | 需要 | 是，可配合微信小程序 |

安卓 App 的数据不会自动出现在电脑网页端；微信小程序的数据也不会自动出现在离线安卓 App 中。

## 二、主要功能

### 预约与算价

- 场景：教室、书房、白棚、办公室、游戏部。
- 自动识别工作日、节假日和调休日价格。
- 单场至少 2 小时。
- 最小预约单位为 30 分钟。
- 营业时间为 10:00-22:00，区间外按每小时 30 元计算加班费。
- 超出场景人数限制后，每人加收 50 元超人费。
- 订金等于预约日期对应价格下的 1 小时租金。

### 档期与撞档

- 同一场景、同一天、实际预约时间重叠时，系统阻止保存。
- 已取消订单不再占用档期。
- 15 分钟收尾时间不占用档期，因此不会阻止下一单紧接着开始。
- 如果前后两单相隔不足 15 分钟，系统会显示醒目的紧邻档期提醒，方便棚主提醒客户准时收尾。
- 多窗口同时操作时，系统会进行本地并发校验；联网云函数还会使用 `booking_locks` 防止同时提交造成撞档。

### 订单与收入

- 订单状态：待确认、已付订金、已完工、已取消。
- 只有修改日期、开始时间或结束时间才计为改签。
- 只修改人数不会增加改签次数。
- 第二次及以后改签提示加收 50 元改签费。
- 收入页面支持订金、尾款、全款、加收和其他收入。
- 可查看今日、本周、本月实际到账金额。
- 预计订单金额不会自动计入收入，必须在“收入”页面手动记账。

### 备份与说明

- 支持导出和导入 JSON 备份。
- 支持合并导入和覆盖导入。
- 订单、收入和自定义节假日规则可以一起备份。
- App 设置页可以打开自适应一图流和版本更新内容。

## 三、仓库目录说明

```text
安卓安装包/                         给朋友安装和阅读说明书
android-app/                        安卓 App 的 Capacitor 工程
offline-app/                        离线网页 App 源代码

cloudfunctions/bookingApi/          微信云开发预约接口
web-admin/                          Vue 3 + TypeScript 电脑后台
tests/                              自动化测试

```

### 重要文件

- `offline-app/index.html`：离线 App 主页面。
- `offline-app/app.js`：离线预约、档期、收入和备份逻辑。
- `cloudfunctions/bookingApi/index.js`：云函数接口和并发控制。
- `cloudfunctions/bookingApi/lib/core.js`：日期、时间、算价和预约规则校验。
- `web-admin/src/App.vue`：电脑 Web 管理后台。
- `tests/`：核心业务和安卓工程测试。

## 四、给朋友使用安卓 App

1. 将 `安卓安装包/夏暮工作室摄影棚预约-v1.2.apk` 发送到安卓手机。
2. 点击 APK 安装；如系统提示允许安装未知来源应用，请按手机提示允许。
3. 安装后打开“夏暮工作室摄影棚预约”。
4. 首次使用先进入“设置”，检查场景价格和节假日规则。
5. 收到客户实际付款后，进入“收入”点击“记一笔”。
6. 每天营业结束后，进入“设置”导出 JSON 备份。

建议保留 APK 和说明书，不要卸载旧版后再安装新版。升级时直接覆盖安装，并选择“更新”，这样可以保留原有数据。

## 六、微信小程序和 Web 后台部署

这部分适合有微信开发者工具和云开发经验的人使用。

### 1. 配置云环境

1. 用微信开发者工具导入项目根目录。
2. 在 `miniprogram/utils/config.js` 填写云开发环境 ID。
3. 复制 `web-admin/.env.example` 为 `web-admin/.env.local`。
4. 在 `.env.local` 填写同一个云开发环境 ID。
5. 上传并部署 `cloudfunctions/bookingApi` 云函数。

### 2. 创建云数据库集合

至少创建以下集合：

```text
scenes
bookings
holidays
admins
booking_locks
```

然后调用云函数 `seedDefaults` 初始化场景价格。

### 3. 支持的云函数 action

```text
getScenes
calculateBookingFee
checkBookingConflict
createBooking
adminSearchBookings
adminUpdateBooking
seedDefaults
```

管理员接口会检查 `admins` 集合中的 `openid` 是否启用。不要把管理员权限直接写死在前端页面中。

### 4. 启动 Web 后台

```bash
cd web-admin
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 七、自动测试与安卓构建

项目根目录测试命令：

```bash
npm test
```

当前测试覆盖：

- 工作日、节假日和调休日算价。
- 加班费、超人费和订金计算。
- 2 小时起租和 30 分钟粒度。
- 非法日期和非法时间。
- 实际时间撞档和取消订单。
- 15 分钟紧邻档期提醒。
- 改签次数和改签费用提示。
- 并发预约锁逻辑。
- 安卓工程是否误申请网络权限、是否依赖私密签名文件。

安卓 Release 构建需要 Android SDK。可设置 `ANDROID_HOME`，或在 `android-app/android/local.properties` 中配置 `sdk.dir`。

正式签名配置示例：

```text
android-app/android/keystore.properties.example
```

复制为 `keystore.properties` 后填写自己的签名信息。私钥和真实密码禁止提交到 GitHub。没有正式私钥时只能构建本地测试包，不要将测试签名包作为正式发布包。

GitHub Actions 会在提交或合并请求时自动运行测试和 Web 构建。

## 九、数据安全和常见问题

### 关机后数据会不会消失？

正常关闭 App、关闭网页、电脑关机或手机重启，一般不会丢失已保存的数据。卸载 App、清除浏览器数据、清除应用数据、恢复出厂设置或设备损坏，可能导致数据丢失。

### 为什么手机和电脑看不到同一批订单？

离线安卓 App 和离线电脑网页各自保存本地数据，不会自动同步。需要手机和电脑同步，必须使用微信小程序加云数据库，或另行开发联网版。

### 订单金额为什么没有计入收入？

订单金额是预计应收金额。只有实际收到钱后，在“收入”页面保存收款记录，才会计入日、周、月收入。

### 前后两单只相差几分钟，为什么没有阻止？

当前规则是：15 分钟收尾时间不占用档期。实际预约时间不重叠时可以保存，但会显示紧邻档期提醒，棚主需要提醒下一单客户提前候场，并提醒上一单客户准时收尾。

### 如何换手机？

旧手机进入“设置”导出 JSON；新手机安装 App 后进入“设置”，选择“合并导入”。导入前建议保留一份原始备份文件。
