# 摄影棚预约管理 · 公开版

基于夏暮离线版 v1.2 的独立公开版本，支持工作室品牌、置景和收费规则配置。无需服务器或账号；数据只保存在当前设备。

## 使用

打开 `index.html`。保持同目录下的 JavaScript、样式和图片文件完整。首次启动填写工作室、置景及规则。

- [使用说明](./使用说明.html)
- [一图流](./一图流.html)
- [可编辑文字说明](./使用说明.md)

安卓工程位于 `../public-android/`，与原夏暮专用版使用不同包名和本地数据空间。

## 数据

修改价格不自动重算历史订单；停用置景保留历史。备份包含品牌、Logo、置景照片、规则、订单和收入。支持夏暮版旧 JSON 备份迁移。导入导出用于手动迁移，不提供手机电脑实时同步。

## 公开版 1.1.0

- 今日工作台与日周可操作档期，空闲时间点击预填。
- 分步预约与快捷录入，设置分组入口。
- 退款关联原收款、部分退款上限校验、作废留痕与净收款统计。
- 本地 PNG 预约确认单，隐私可选，系统分享或下载。

- 自定义工作室资料、图片和预设主题。
- 自定义置景数量、价格、人数、排序及启停状态。
- 共用场地撞档检查。
- 可配置起租、时间步长、营业时间、订金和附加费。
- 订单保留收费快照，改签可选择原规则或当前规则。
- 保留预约、订单、档期、收入、备份和原有手势操作。
- “联系作者”入口可离线查看作者二维码。

1.0.2 更新作者二维码原图；1.0.1 新增联系方式、账号复制和二维码查看。当前支持适应屏幕、放大和还原。

App 内品牌可以修改，安卓桌面的名称和图标使用统一标识。首版不支持跨夜订单、多门店、联网同步或在线支付。
