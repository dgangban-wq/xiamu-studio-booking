# 摄影棚预约管理 · 公开版 v1.1.0

## 下载与安装

- 安卓手机下载 `摄影棚预约管理-v1.1.0.apk`，打开安装。
- 需要电脑版、图文说明和一图流，下载 `摄影棚预约管理-公开版1.1.0-安装包和说明.zip` 并完整解压。
- GitHub 文件页面显示的是文件信息，点击下载按钮才能取得安装包。
- 支持 Android 7.0 及以上；本应用不申请互联网权限。

## 公开版功能

自定义工作室名称、Logo、置景数量、价格和收费规则。1.1.0 新增今日工作台、日周档期快速预约、分步录入、部分退款与作废留痕、预约确认单分享、设置分组。收尾仍只提醒，不强制占档。

## 升级与数据

公开版与夏暮专用版可同时安装，各自保存数据。公开版 v1.0 / v1.0.1 升级到 v1.1.0 时直接覆盖安装，勿先卸载；操作前建议导出备份。手机电脑不会自动同步。

本包完成自动化测试、浏览器流程测试及 APK 验签；尚未完成安卓真机安装与系统分享测试。
